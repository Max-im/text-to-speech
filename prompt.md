# ТЗ: веб-страница озвучки текста

Сделай одну простую страницу, которая озвучивает введённый текст и сохраняет звук в файл. Всё работает в браузере, без сервера и без аккаунтов.

## Как это работает (главное)

Текст превращает в речь **нейросетевая модель озвучки (TTS)**, а не страница и не сервер. Страница только передаёт ей текст, голос и скорость, а потом получает звук.

- Модель: Kokoro-82M (формат ONNX), около 80 МБ. Скачивается с Hugging Face при первом открытии страницы и дальше лежит в кэше браузера.
- Библиотека-обёртка: `kokoro-js` (npm). Она запускает модель прямо в браузере: на видеокарте через WebGPU, а если её нет, на процессоре через WASM.
- Результат: аудио (WAV), которое страница проигрывает и даёт скачать.
- Страница работает в любом современном браузере (Chrome, Edge, Firefox) на Windows, Linux (Ubuntu) и macOS. Ничего устанавливать не нужно. Для разработки нужен только Node.js и любой статический сервер (например, `npx vite`).

## Если нужен только стек

Минимум: HTML + JS, `kokoro-js` (или другой браузерный TTS), Web Audio API (громкость, плеер), запись WAV из полученных сэмплов. Остальное (интерфейс, разбивка текста, прогресс) делается по списку ниже на твоё усмотрение.

## Настройки (заполни перед запуском)

- **Язык озвучки:** английский
- **Голос по умолчанию:** female

## Стек

- Статическая страница: `index.html` + JS (можно без фреймворка). Без бэкенда, чтобы выложить на GitHub Pages / Cloudflare Pages.
- Движок озвучки работает локально в браузере.
  - Для английского: `kokoro-js` (модель Kokoro-82M, WebGPU, если нет, то WASM).
  - Для другого языка: подбери офлайн-модель, которая работает в браузере (например, Piper через WASM), и скажи мне, какую выбрал.
- Модель скачивается один раз и кэшируется в браузере.

## Что должно быть на странице

1. **Поле ввода текста** (многострочное).
2. **Выбор голоса** (список доступных голосов модели).
3. **Скорость речи**: ползунок, например 0.5x до 2.0x, шаг 0.1, по умолчанию 1.0. Передаётся в модель при генерации.
4. **Громкость**: ползунок 0–100%. Действует на проигрывание и на сохраняемый файл.
5. **Кнопка «Озвучить»**: генерирует звук. Во время работы показывает прогресс и кнопку «Отмена».
6. **Плеер**: play/pause и **ползунок позиции** (перемотка), текущее и общее время.
7. **Кнопка «Сохранить»**: скачивает результат как WAV (MP3 по желанию).

## Поведение

- При первом запуске показать индикатор загрузки модели (в процентах) и текст «Модель скачивается один раз».
- Длинный текст разбивать на предложения или абзацы, озвучивать по кускам и склеивать в один файл. Показывать прогресс по кускам.
- Если текст не менялся и настройки те же, повторно не генерировать, а использовать готовый звук.
- Понятные сообщения об ошибках (нет WebGPU, не хватило памяти, пустой текст).
- Интерфейс простой и чистый, работает на телефоне и на компьютере. Тёмная тема по желанию.

## Не делаем

Аккаунты, облако, оплату, видео, музыку, историю проектов, лишние настройки.

## Критерии готовности

- Вставил текст, нажал «Озвучить», услышал голос.
- Скорость и громкость меняют результат; перемотка работает.
- Скачанный файл открывается в обычном плеере и звучит так же, как на странице.
- Страница открывается с бесплатного хостинга по ссылке, ничего ставить не нужно.

## Порядок работы

1. Скелет страницы и подключение модели, озвучка короткой фразы.
2. Поле ввода, голос, скорость, громкость, плеер с ползунком.
3. Разбивка длинного текста, прогресс, отмена.
4. Сохранение в файл, проверка, инструкция по выкладке на хостинг в `README.md` (3–4 строки).
